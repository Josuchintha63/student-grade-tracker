# Student Grade Tracker

A simple Java 21 console application for recording student grades, computing average scores, and determining letter grades.

## Requirements
- Java 21+
- Apache Maven 3.8+

## How to Build & Run
```bash
mvn clean compile
mvn exec:java
```

## Running Tests
```bash
mvn test
```
